# UI reference image

Save the VoxLock Desktop UI concept image from our conversation here.

Recommended file name: **voxlock-desktop-concept.png**

This directory is intentionally versioned without a bundled image so you can
drop in the exact reference you wish to use. The image is a **design target**:
the actual PySide6 UI lives in **src/voxlock_desktop/ui.py**.

You can add variations when refining the interface.
